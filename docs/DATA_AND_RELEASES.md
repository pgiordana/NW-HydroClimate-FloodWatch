# Data and release policy

Large raw meteorological, oceanographic, hydrological and geospatial source data
are not committed to ordinary Git history.

The complete portable NW FloodWatch runtime is distributed as a GitHub Release
asset (`NW_FloodWatch_Mac_Windows.zip`). Source-provider terms and attribution
remain applicable.

Frozen scientific artifacts are versioned. Runtime antecedent caches are
mutable by design and are not equivalent to immutable scientific artifacts.
